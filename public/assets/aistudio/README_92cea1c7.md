# Keno Stats — Android Studio project

This is an educational, offline number-history and frequency tracker. It does not connect to a betting site, accept wagers, predict results, or claim to improve winning odds.

## Build an APK
1. Install Android Studio on a computer.
2. Open this folder (`KenoStatsAndroid`) in Android Studio.
3. Allow Gradle sync and install the Android SDK Platform 35 if prompted.
4. Choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Android Studio will show the generated APK location (usually `app/build/outputs/apk/debug/app-debug.apk`).

Requires JDK 17 and Android Gradle Plugin 8.6.1. The app stores entered history locally on the device.
